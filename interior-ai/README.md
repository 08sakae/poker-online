# 🛋 AI インテリアデザイナー

図面・部屋の写真をアップロードすると、「世界一のインテリアデザイナー」ペルソナのAIが
**実際に購入できる市販家具**(IKEA / ニトリ / 無印良品 / LOWYA / unico / Francfranc)だけで
テイスト別のコーディネート提案書を作成するツールです。

## セットアップ

```bash
cd interior-ai
npm install
export ANTHROPIC_API_KEY=sk-ant-...   # Anthropic APIキー
npm start
```

ブラウザで `http://localhost:3100` を開く。

## 使い方

1. **STEP 1**: 間取り図と室内写真をアップロード(最大6枚)+ 要望メモを入力 →「部屋を解析する」
2. **STEP 2**: AIの現地調査メモ(間取り・既存家具・課題・ポテンシャル)を確認
3. **STEP 3**: テイスト(北欧 / ジャパンディ / インダストリアル 等8種)・プラン・予算を選んで提案書を生成

提案書には家具リスト(商品名・参考価格・配置場所・選定理由)、カラーパレット、
レイアウトの根拠(動線・寸法検証)、予算内の合計金額が含まれます。

## トークンコスト設計

役割ごとに最適なモデルへ振り分けることで、Fable 5 だけで構成した場合と比べ大幅にコストを抑えています。

| 工程 | モデル | 料金(入力/出力 per 1Mトークン) | 理由 |
|---|---|---|---|
| 図面・写真の解析 | **Haiku 4.5** | $1 / $5 | vision対応の最安モデル。構造化出力(JSON Schema)で読み取り精度を担保 |
| 提案生成(スタンダード) | **Sonnet 5** | $3 / $15 | 品質とコストのバランス。effort=medium でさらに節約 |
| 提案生成(プレミアム) | **Opus 4.8** | $5 / $25 | adaptive thinking + effort=high で深い検討 |
| 提案生成(マスター) | **Fable 5** | $10 / $50 | 最上位。refusal 時は Opus 4.8 へ自動フォールバック |

追加のコスト削減策:

- **プロンプトキャッシュ** — 家具カタログを system プロンプト末尾に `cache_control` 付きで配置。
  2回目以降の生成ではカタログ部分の入力が約1/10のコスト(キャッシュ読み取り)になる
- **ブラウザ側で画像リサイズ** — 送信前に長辺1568pxへ縮小し JPEG 圧縮。高解像度画像の
  画像トークン増(最大約3倍)を回避
- **コストの可視化** — 画面下部に毎リクエストのトークン数と累計概算コスト(USD/円換算)を表示

## アーキテクチャ

```
interior-ai/
├── server/
│   ├── index.js      # Express + SSEストリーミング。/api/analyze, /api/propose
│   ├── models.js     # モデルルーティングと料金計算
│   ├── prompts.js    # ペルソナ・解析スキーマ・テイスト定義
│   └── catalog.json  # 市販家具カタログ(約35点。自由に追加・差し替え可)
└── public/
    └── index.html    # フロントエンド(画像リサイズ・SSE描画・コスト表示)
```

- `/api/analyze` — 画像(base64)を受け取り、Haiku 4.5 の vision + structured outputs で
  部屋の構造・既存家具・課題を JSON 化
- `/api/propose` — 解析結果+テイスト+予算を受け取り、選択プランのモデルで提案書を
  ストリーミング生成(Server-Sent Events)

## カスタマイズ

- **家具を増やす**: `server/catalog.json` の `items` に追記(id / category / brand / name /
  price_jpy / size_cm / styles / url)。カタログはキャッシュされるため、大きくしても
  2回目以降のコスト影響は小さい
- **テイストを増やす**: `server/prompts.js` の `TASTES` に追記
- **為替レート**: `public/index.html` の `USD_JPY` を変更

## 注意事項

- カタログの価格・サイズは参考値です。URLは各ブランドの検索ページを指しています
- 提案はAIによる生成物です。購入前に実寸・在庫・現行価格を必ずご確認ください
